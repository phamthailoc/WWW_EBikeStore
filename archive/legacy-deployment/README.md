# Legacy deployment files

This folder preserves deployment and automation files from the previous setup. They are not used by the current local Spring Boot + Thymeleaf application.

- `root/`: previous root Docker frontend setup, nginx config, EC2 deployment notes, and GitHub Actions workflows.
- `backend/`: previous Docker Compose, Dockerfile, nginx scaling config, and deployment/backup scripts.

Current application source, MariaDB setup SQL, product images/data, and the `packages/web` reference UI remain in their original locations.
