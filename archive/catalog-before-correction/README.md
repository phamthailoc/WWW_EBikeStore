# Previous catalog data

This archive preserves the previous mixed gasoline/electric catalog, inferred specifications, automatically assigned color names and original image downloads. It is not loaded by the current application or SQL generator.

The active reviewed catalog is `backend/database/catalog/products.json`; runtime images are under `backend/src/main/resources/static/images/catalog/`.

Gasoline models removed from sale: Sir 50CC, Creer 50CC, Gofast 50CC, Pansy XS1 upgraded, Pansy XS, Pansy XS1, RS 50CC and Tesla X 50CC. Existing database rows remain inactive so historical orders are preserved.
